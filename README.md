# Xntrova Homepage Redesign

A responsive, single-page homepage concept created for the Frontend Developer homepage redesign assessment.

## Tech stack
- React
- Vite
- CSS
- lucide-react icons

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open a terminal in this folder (the folder containing `package.json`).
4. Run:

   ```bash
   npm install
   npm run dev
   ```
5. Open the local URL printed in the terminal, usually `http://localhost:5173/`.

To check a production build, run `npm run build`.

## Features
- Responsive desktop, tablet, and mobile layout
- Sticky navigation with a mobile menu
- Smooth section navigation and calls to action
- Header/navigation, hero, services, about, key benefits, process, concept portfolio, testimonial-style section, CTA, contact form, and footer
- Required-field and browser-native email validation
- Form success state for demonstration
- Testimonials section uses clearly labelled illustrative copy, not fabricated real client feedback
- Reduced-motion preference support

## Important notes
- Portfolio cards are explicitly labelled as concept work; they are not claims of completed client projects.
- The assessment brief does not require a backend. The contact form currently validates inputs in the browser and displays a demo confirmation; it does **not** send or store enquiries. This keeps the assessment frontend-only. A backend or form service is needed only if real enquiries must be delivered or stored.
- Review the code and be ready to explain your implementation in the assessment interview.
